# 수강 횟수 가격정책 — 관리자 설정 가이드

수업(lesson) 하나를 **1회 / 4회 / 8회** 같은 횟수 묶음으로 팔고, 묶음이 커질수록 할인해주는 기능이다.
결제 페이지에서 사용자가 옵션을 고르면 그 옵션의 가격이 결제 금액이 된다.

이 문서는 **관리자 화면에서 무엇을 입력받아야 하는지**를 정의한다.
클라이언트(웹/앱)는 이미 구현돼 있고, 관리자·BE가 아래 스펙대로 데이터를 채워주면 연동된다.

---

## 1. 데이터 모델

가격정책은 **수업의 하위 목록**이다. 수업 1개가 정책 N개를 가진다.

```ts
lesson.pricePolicies: PricePolicy[]
```

| 필드 | 타입 | 필수 | 설명 |
|---|---|:---:|---|
| `id` | number | ✅ | 정책 고유 id. 결제 시 `policyId`로 전송돼 **어떤 옵션을 샀는지 식별**한다 |
| `count` | number | ✅ | 수강 횟수. 이 옵션을 사면 발급되는 수강 가능 횟수 |
| `price` | number | ✅ | **실제 결제 금액** (총액, 회당 아님) |
| `originalPrice` | number | | 할인 전 정가. 넣으면 취소선 + 할인율 배지 노출 |
| `label` | string | | 표시 라벨. 비우면 `{count}회`로 자동 표기 |
| `description` | string | | 보조 설명 (예: `주 2회 4주 과정`) |
| `badge` | string | | 강조 배지 (예: `최대 할인`, `가장 인기`) |
| `recommended` | boolean | | 기본 선택될 옵션. **정책당 1개만** |
| `expiryDays` | number | | 구매일로부터 사용 기한(일). 회차 소진 마감 안내용 |

### 입력받지 않는 값 (자동 계산)

관리자가 넣지 **않는다.** 클라이언트가 계산한다.

| 값 | 계산식 |
|---|---|
| 회당 가격 | `price / count` |
| 할인율 | `floor((1 - price / originalPrice) × 100)` — 실제보다 커 보이지 않게 버림 |
| 절약 금액 | `originalPrice - price` |

> 이 값들을 관리자에서 따로 입력받으면 `price`와 어긋났을 때 **표시 금액과 실제 결제 금액이 달라진다.**
> 파생값은 반드시 한 곳에서만 계산되어야 한다.

## 2. 관리자 화면에 필요한 것

### 2.1 위치

수업 등록/수정 화면 안의 **선택 섹션**. 기본은 꺼짐(기존처럼 `lesson.price` 단건 결제).

```
[ ] 수강 횟수별 가격 사용
```

체크하면 아래 목록 편집기가 열린다.

### 2.2 정책 목록 편집기

행 추가/삭제 + **순서 변경(drag)** 이 필요하다. 결제 화면은 **배열 순서 그대로** 노출하므로, 순서가 곧 노출 순서다.

행 하나당 입력:

| 컨트롤 | 필드 | 비고 |
|---|---|---|
| 숫자 입력 | `count` | 1 이상 정수 |
| 금액 입력 | `price` | 0 이상 정수 (원 단위) |
| 금액 입력 | `originalPrice` | 비워도 됨 |
| 텍스트 | `label` | 비우면 `{count}회` 자동 |
| 텍스트 | `description` | 짧게 (한 줄) |
| 텍스트 | `badge` | 짧게 (4~6자 권장) |
| 라디오 | `recommended` | 목록 전체에서 1개만 |
| 숫자 입력 | `expiryDays` | 비워도 됨 |

### 2.3 미리보기

입력하는 동안 **회당 가격 / 할인율 / 절약액**을 실시간으로 보여줄 것.
관리자가 `price`를 잘못 넣어도 "회당 얼마"를 보면 즉시 알아챈다. 오입력 방어에 가장 효과가 크다.

```
8회  200,000원  (정가 280,000원 · 28% 할인 · 회당 25,000원)
```

## 3. 검증 규칙

저장 시 막아야 하는 것:

| 규칙 | 이유 |
|---|---|
| `count` ≥ 1, 정수 | 0회권은 의미가 없다 |
| `price` ≥ 0, 정수 | 원 단위. 소수점 금액은 PG가 거절한다 |
| `originalPrice` > `price` | 정가가 더 싸면 할인율이 음수가 되고 취소선이 거짓말이 된다. 같거나 작으면 **저장 거부하거나 `originalPrice`를 비워서 저장** |
| `count` 중복 금지 | 같은 횟수의 옵션이 2개면 사용자가 구분할 수 없다 |
| `recommended`는 최대 1개 | 2개 이상이면 기본 선택이 모호해진다 |
| 정책 사용 시 최소 1행 | 켜놓고 비워두면 결제 화면에 아무것도 안 뜬다 |
| 회당 가격 역전 경고 | 8회가 4회보다 회당 비싸면 **경고**(차단은 아님). 의도한 구성일 수 있으나 대부분 오입력이다 |

## 4. 결정이 필요한 정책 이슈

클라이언트만으로는 못 정한다. **기획/BE 확인 필요.**

### 4.1 판매 후 수정

이미 구매자가 있는 정책의 `price`·`count`를 바꾸면 어떻게 되나?

- 기존 구매자의 남은 횟수는 **구매 시점 `count`를 따라야** 한다 (정책을 참조하면 소급 변경돼버림)
- → 결제 시점에 `count`/`price`를 **티켓에 복사해 저장**하는 것을 권장

### 4.2 정책 삭제

미사용 횟수가 남은 구매자가 있는 정책은 **하드 삭제 금지**.
`isActive: false` 같은 비활성 플래그로 숨기고, 신규 판매만 막는 방식이 안전하다.

> 현재 타입에는 이 필드가 없다. 필요하면 `PricePolicyResponse`에 추가해야 한다.

### 4.3 `lesson.price`와의 관계

정책이 있으면 `lesson.price`는 무시되나, 목록·상세 화면에는 여전히 `lesson.price`가 노출된다.

- 정책이 있을 때 수업 카드에 표시할 대표가는 무엇인가?
- 제안: **최저가 옵션의 회당 가격** (`min(price/count)`) — "회당 25,000원부터"

### 4.4 기존 할인/패스권과의 중복

결제 화면에는 패스권·쿠폰·할인이 이미 있다. 횟수 할인과 **중복 적용 가능한가?**
현재 클라이언트는 정책 가격을 상품가로 두고 그 위에 기존 할인을 얹는다. 이게 의도한 동작인지 확인 필요.

### 4.5 만료

`expiryDays`가 지나면 남은 횟수는 소멸인가, 연장 가능인가? 소멸이면 환불 기준은?

## 5. 연동 체크리스트

- [ ] BE: `GET /payment` 응답의 `lesson.pricePolicies`에 배열 내려주기
- [ ] BE: 결제 요청의 `policyId` 수신 → 해당 정책 가격으로 검증
      (**클라이언트가 보낸 금액을 믿지 말 것.** `policyId`로 서버에서 재조회해 금액 대조)
- [ ] BE: 결제 성공 시 `count`만큼 수강 가능 횟수 발급
- [ ] 관리자: 위 편집기 구현
- [ ] FE: **목업 제거** — `src/app/payment/price.policy.mock.ts` 삭제 +
      `UnifiedPaymentInfo.tsx`의 `MOCK_PRICE_POLICIES` 폴백 제거
      (연동 후에도 폴백을 남기면 응답 누락 시 조용히 가짜 가격으로 돌아간다)

## 6. 예시 데이터

```json
{
  "pricePolicies": [
    { "id": 1, "count": 1, "price": 35000 },
    {
      "id": 2, "count": 4, "price": 120000, "originalPrice": 140000,
      "description": "주 1회 4주 과정", "expiryDays": 60
    },
    {
      "id": 3, "count": 8, "price": 200000, "originalPrice": 280000,
      "description": "주 2회 4주 과정", "badge": "최대 할인",
      "recommended": true, "expiryDays": 90
    }
  ]
}
```

렌더 결과:

```
많이 들을수록 할인

  1회                        35,000원
  4회  14%      140,000원 → 120,000원   회당 30,000원
  8회  28%      280,000원 → 200,000원   회당 25,000원   [최대 할인]
       할인 금액 80,000원 · 구매일로부터 90일
```
